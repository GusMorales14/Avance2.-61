# Avance2.-61

## Proyecto Integrador — Avance 2: Ingeniería de características

Repositorio correspondiente al segundo avance del proyecto integrador del Equipo 61, enfocado en la preparación de datos e ingeniería de características para la inferencia de propiedades físicas de galaxias mediante técnicas de aprendizaje automático.

---

## Descripción del proyecto

El proyecto forma parte de una colaboración académica relacionada con el análisis de datos astronómicos provenientes del contexto del Observatorio Vera C. Rubin y el estudio de propiedades físicas galácticas.

En este avance se desarrollan tareas asociadas a la etapa de **Data Engineering (Data Preparation)** propuesta en la metodología **CRISP-ML(Q)**, incluyendo:

- Limpieza y validación de datos
- Imputación de valores faltantes
- Transformaciones estadísticas
- Escalamiento y normalización
- Ingeniería de características
- Discretización (*binning*)
- Codificación de variables categóricas
- Selección y extracción de características
- Reducción de dimensionalidad
